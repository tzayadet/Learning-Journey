# Learning Journey

Repositorio de aprendizaje estructurado para programación y bases de datos. Agrupa ejercicios por tema y nivel, con los materiales y soluciones organizados en proyectos independientes.

## Rutas de aprendizaje

### Databases
- [Hello SQL Exercises](databases/hello-sql-exercises/README.md) · Práctica progresiva de lectura, escritura, tablas, relaciones, JOIN y consultas avanzadas.

### Programming
- [Python Fundamentals](programming/python-fundamentals/README.md) · Fundamentos de Python, ejercicios básicos e intermedios, backend y conceptos web relacionados.

## Cómo utilizar este repositorio

1. Entra en la ruta de aprendizaje que quieras trabajar.
2. Lee su README para conocer los requisitos y la estructura.
3. Avanza por los módulos en orden cuando el contenido esté secuenciado.
4. Ejecuta los ejercicios en un entorno local y conserva tus soluciones separadas del material original.

## Alcance

Material de formación y práctica. Los ejercicios pueden tener distintos niveles de madurez y no representan por sí solos aplicaciones de producción.
